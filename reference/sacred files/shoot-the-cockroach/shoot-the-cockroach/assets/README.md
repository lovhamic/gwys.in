# Assets Directory

Place optional game assets here:

## cockroach.png
- 40x40 pixels (or similar)
- Transparent background (PNG with alpha)
- Top-down view of a cockroach
- Will be scaled to COCKROACH_SIZE (default 40px)

## shoot.wav
- Short shooting sound effect
- WAV format, 44.1kHz, 16-bit
- Duration: ~0.1-0.2 seconds

## hit.wav
- Hit confirmation sound
- WAV format, 44.1kHz, 16-bit
- Duration: ~0.2-0.5 seconds

## background.png
- Game background image
- Size: 1024x768 (matches SCREEN_WIDTH x SCREEN_HEIGHT)
- Dark/neutral colors recommended for visibility

---

The game works perfectly without these assets - it uses procedural drawing as fallback.
